# Local model assets

Quantized ONNX export of `sentence-transformers/all-MiniLM-L6-v2`, bundled to avoid network downloads or AI keys during requests. Revision, source URLs and SHA-256 values are recorded in `manifest.json`. Model weights were verified against the publisher's Hugging Face LFS SHA-256; tokenizer bytes were verified against its Git blob ID. Startup verifies the stored SHA-256 values again.

The upstream model is licensed under Apache-2.0. These assets provide semantic embeddings only, not a generative language model. Answers are extracted from retrieved official website evidence.
